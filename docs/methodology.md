# 분석 방법과 평가 전제

## 데이터와 예측 목표

- 데이터: MIT–Stanford 공개 배터리 실험의 세 배치 MAT 파일.
- Batch 1: `2017-05-12` / 학습 46 셀.
- Batch 2: `2018-02-20` / 원본 47 셀, 유효 타깃 39 셀.
- Batch 3: `2018-04-12` / 원본 46 셀, 유효 타깃 44 셀, 추가 검증.
- 태스크: **Regression**, 원본에 기록된 `cycle_life`(총 사이클 수).
- 입력 시점: 실제 cycle2–100 의 요약과 cycle10·100 의 방전 곡선.
- 종료 QD·knee·전체 관측 길이는 진단 메타데이터이며 학습 입력 목록과 분리한다.

정답 결측 10 셀은 점수 계산에서 분리한다. Batch 1 의 13 셀은 종료 용량이 0.885Ah보다 높아, 기록된 수명을 모두 완료된 80% EOL로 동일하게 해석하기 어렵다. `cycle_life-100`은 100 사이클 시점의 잔여 사이클 표현이며 주 지표는 총수명에 대해 계산한다.


## 피처·모델 전략

물리 5 는 `logvar_deltaQ`, `slope_QD`, `delta_IR`, `mean_Tavg`, `mean_chargetime`이다. 정책 묶음은 물리 5 에 `C1/SOC_switch/C2`를 추가한다. 전류 묶음은 충전 시간을 `current_rms_C/current_cv`로 대체한다. 원본 I는 C-rate, t는 분이며 다시 공칭용량으로 나누지 않는다. ΔQ는 셀별 실제 Vdlin 축에 정렬한 Q100-Q10 의 표본분산(ddof=1)을 log10 변환한다.

| 후보 | 최선 설정 | CV MAPE(%) | 폴드 SD(%p) | CV MAE(사이클) |
|---|---|---:|---:|---:|
| M0 중앙값 기준 | 학습 수명 중앙값 | 19.63 | 10.23 | 150.01 |
| M1 단일 Ridge | ΔQ 1 개, raw, alpha=1 | **7.12** | 3.00 | 59.63 |
| M2 다변량 Ridge | 물리 5, raw, alpha=0.01 | 7.37 | 1.45 | 61.59 |
| M3 Random Forest | 전류 묶음, log10, depth2, leaf3 | 9.77 | 4.61 | 79.87 |

M1/M2 는 동일 Ridge 알고리즘의 입력 구성 비교다. 후보 65 개 설정을 동일 5 폴드에서 325 회 학습했다. Ridge alpha=0.01/0.1/1/10/100, 타깃 raw/log10 을 비교했다. RF는 200 트리, depth2/4, 최소 leaf3/6, seed42 로 제한했다.

선정 규칙은 최소 평균 MAPE를 찾고, best 평균+best SD/√5 이내에서는 Ridge를 우선하며 같은 계열에서 최소 평균 MAPE를 택하는 것이다. 현재 문턱은 8.46% 다. M1 이 가장 낮은 평균 오차를 보였고 M2 의 추가 입력은 평균 개선으로 이어지지 않았다. M2 의 낮은 변동성은 추가 표본에서 재검토할 근거다. one-SE는 복잡도 제어 기준이며 유의성 검정이 아니다.

수명 규모가 다른 셀의 상대 오차를 비교하기 위해 MAPE를 주 지표로 선택했다. MAE·폴드 변동성·과대 예측 지표로 사이클 단위의 오차, 안정성, 점검 지연 위험을 함께 검토한다.


## 검증 파이프라인

1. seed42 의 정책 단위 GroupShuffleSplit로 Batch 1 개발 35 셀·18 정책과 Hold-out11 셀·5 정책을 분리한다.
2. 개발 집단에 5-fold GroupKFold를 적용해 후보를 선택한다. 각 폴드에서 결측 중앙값과 Ridge 표준화 값을 다시 추정한다.
3. 최종 설정을 저장한 후 35 셀 개발 모델로 Hold-out을 평가한다.
4. 동일 설정으로 전체 Batch 1 46 셀을 재학습하고 Batch 2·3 을 각각 평가한다.
5. 정책·수명 범위·품질별 오류 분석은 고정 이후의 진단이다.

CV와 Hold-out의 정책 중복은 0 이다. 모델 선택에 Hold-out/Test 점수를 되돌려 사용하지 않았다. 모델 설계 단계에서 모든 배치 EDA와 이전 탐색 점수를 본 이력이 있으므로 결과는 고정 절차의 외부 적용 검증이며, 완전히 새 미열람 테스트의 의미로 확대하지 않는다. 물리 셀 barcode/channel은 MATLAB 객체 참조 형식이어서 파일 간 동일 셀 여부의 검증 한계가 남는다.


## 오류 분석

- **Batch 2 의 단수명 과대 예측:** 학습 최단 534 사이클보다 짧은 30 셀은 MAPE37.81% 이고 모두 과대 예측이다. 학습 수명 범위 9 셀은 14.14% 다. 가장 큰 오차는 b2c6·b2c15(3.6C(9%)-5C), b2c18(5.2C(50%)-4.25C)에서 나타난다. 이 세 셀의 초기 ΔQ가 학습 입력 범위 안에 있어도 실제 393–449 사이클을 678–753 사이클로 추정한다. 입력 범위 안 전체 28셀의 MAPE도 34.90%다.
- **Batch 3 의 장수명 과소 예측:** 학습 최대 1227 사이클을 초과하는 9 셀은 모두 과소 예측, MAPE26.59%·MAE450.26 사이클이다. 학습 수명 범위 35 셀은 MAPE9.17% 다. 큰 오차 셀은 newstructure 정책과 1801–1935 사이클 수명 영역에 나타난다.
- **평균 지표의 한계:** 두 배치의 MAE는 약 159 사이클로 같지만 MAPE는 32.35%/12.74% 다. 타깃 분포와 오차 방향을 분리해 교체 지연과 조기 교체의 함의를 해석해야 한다.
- **품질 민감도:** 저자 순서 규칙을 원본에 대응시킨 Batch 3 의 수집 문제 b3c37, 잡음 b3c2·b3c42·b3c43 을 표기했다. 동일 고정 모델의 민감도 40 셀 MAPE12.78% 는 주 평가 44 셀 12.74% 와 유사하다. 품질 필터만으로 일반화 문제가 해결된다는 근거는 약하다.

정책 단위 bootstrap95% 구간은 Hold-out8.26–16.44%, Batch 2 24.28–40.87%, Batch 3 9.11–17.13% 다. 해당 집단 구성의 점수 변동이며 새 배치의 불확실성이나 개별 셀의 예측구간 전체를 보장하지 않는다.

실제 수명 구간은 사후 진단값이며 운영에서 새 셀의 수명을 미리 알 수 없다. 적용 여부는 정책·구조·온도 같은 관측 가능한 정보와 신규 집단 검증으로 판단한다.

정책·셀 구조·수집 시기의 차이는 원인 가설이다. 관찰 자료만으로 각 요인의 인과 효과를 확정할 수 없다. 현재 테스트를 개선 자료로 쓰는 경우 수정 모델의 판단에는 새 테스트 집단이 필요하다.


## ESS 운영 해석

수명 순위 Spearman은 Batch 2=0.709, Batch 3=0.797 이다. 절대 교체 시점보다 점검 우선순위에 활용할 가능성이 있으나 상위 위험 셀 탐지율이나 비용 절감이 검증된 결과는 아니다.

현장 적용의 우선순위는 완전한 EOL 라벨·물리 셀ID 확보, 단수명·장수명 개발 표본 보강, 정책·구조별 교정의 신규 검증이다. 이후 SOC·DoD·온도·캘린더 열화·팩 불균형이 있는 실제 ESS에서 입력 가용성과 오류 비용을 평가한다. 점검 우선순위는 위험 셀 적중률로, 교체 일정은 수명 구간별 bias·과대 예측 손실·예측구간으로 각각 검증한다.

시사점 표만 다시 생성하려면 `python -m src.insights --root . --results results`를 실행한다. `src.finish`도 같은 표를 생성한다. 입력은 저장된 피처·후보 비교·셀 예측·품질 민감도이며, 시사점 계산은 후보 선택 이후에 수행한다.
