# 초기 열화 신호의 해석과 ESS 운영 의사결정

최종 모델은 ΔQ 로그 분산 한 개를 입력으로 사용하는 Ridge(alpha=1, 총수명 회귀)다. 이번 분석에서 얻은 핵심은 **복잡한 모델의 도입보다 신호의 타당성, 적용 조건, 오차가 만드는 판단 위험을 먼저 검증해야 한다는 것**이다.

Batch 1 정책 분리 CV MAPE는 7.12%, Hold-out 12.72%, Batch 2 32.35%, Batch 3 12.74%다. MAPE는 상대 오차이며 정확도 백분율이 아니다. 아래 발견은 배치별 EDA와 고정 모델 평가에서 나온 관찰을 의사결정 기준으로 연결한다.

## I1. 절대 용량보다 변화량에 남는 수명 신호

**관찰:** QD2-수명 r: 전체 -0.525, 배치 중심화 -0.013; ΔQ 로그 분산-수명 r: 전체 -0.851, 중심화 -0.773

**해석:** 전체 상관에는 배치 평균 차이가 섞인다. ΔQ의 관계는 배치 평균을 구분한 뒤에도 유지된다.

**의사결정 시사점:** 전체 상관 순위만으로 피처를 고르지 않고, 변화량 신호를 기준으로 정책 그룹 검증에서 추가 입력의 기여를 비교한다.

**해석 조건:** 중심화는 배치 수준 평균을 구분하는 진단이며 운전 조건의 인과 효과를 제거하는 실험이 아니다.

근거: [data/processed/cells_and_features.csv](../data/processed/cells_and_features.csv) · 개발·검증 보고서 2쪽 · EDA 5절의 배치 중심화 진단

## I2. 센서 추가의 기여와 모델 복잡도의 구분

**관찰:** M1 단일 Ridge 7.12%, M2 다변량 Ridge 7.37%, M3 RF 9.77%; M2 폴드 SD 1.45%p, M1 3.00%p

**해석:** 추가 센서 묶음은 평균 오차를 개선하지 못했다. 평균 오차와 폴드 변동성은 별도 판단 근거다.

**의사결정 시사점:** 추가 센서 수집·비선형 모델 도입은 같은 분할에서의 증분 가치로 판단한다. 낮은 M2 변동성은 추가 표본에서 재검토한다.

**해석 조건:** 개발 35셀의 조건부 비교다. 작은 성능 차이가 통계적으로 유의하거나 다른 배치에서도 유지된다고 단정하지 않는다.

근거: [results/candidate_comparison.csv](../results/candidate_comparison.csv) · 개발·검증 보고서 4쪽 · 모델링 5절의 후보 비교

## I3. 평균 상대 오차가 가리는 운영 위험의 방향

**관찰:** Batch 2/3 MAE 159.28/159.41사이클, MAPE 32.35/12.74%; Batch 2 과대 예측 35/39셀

**해석:** MAPE의 분모가 되는 실제 수명 규모가 다르다. 낮은 상대 오차만으로 다른 배치의 운영 적합성이 더 좋다고 판단하기 어렵다.

**의사결정 시사점:** 점검 지연 위험은 단수명 과대 예측, 조기 교체 위험은 장수명 과소 예측으로 구분해 수명 구간별 MAE·bias와 오류 비용을 평가한다.

**해석 조건:** 점검 지연·조기 교체는 오차 방향에 따른 가능성이다. 실제 비용과 현장 교체 결과는 측정하지 않았다.

근거: [results/cell_predictions.csv](../results/cell_predictions.csv), [results/evaluation_metrics.csv](../results/evaluation_metrics.csv) · 개발·검증 보고서 7–8쪽 · 모델링 7절의 배치별 오차

## I4. 입력 범위 검사만으로 확인하기 어려운 적용 영역

**관찰:** Batch 2 ΔQ 학습 범위 안 28/39셀, 해당 MAPE 34.90%; 학습 최단수명 미만 30셀 MAPE 37.81%; Batch 3 학습 최대수명 초과 9셀 MAE 450.26사이클

**해석:** 입력이 익숙한 범위여도 수명과의 대응 관계가 달라질 수 있다. 학습 수명 범위의 양쪽 끝에서 큰 오차가 남는다.

**의사결정 시사점:** 정책·셀 구조·수집 조건을 포함한 새 검증 집단과 단수명·장수명 개발 표본을 확보한다. 입력 범위 안이라는 이유만으로 자동 결정을 허용하지 않는다.

**해석 조건:** 실제 수명 구간은 사후 진단이다. 운영에서는 새 셀의 정답 수명을 미리 알 수 없고, 정책·구조·불확실성 등 관측 가능한 정보가 필요하다.

근거: [results/lifetime_range_errors.csv](../results/lifetime_range_errors.csv), [results/cell_predictions.csv](../results/cell_predictions.csv) · 개발·검증 보고서 9–10쪽 · 모델링 8절의 적용 범위

Batch 2의 입력 범위 안 28셀은 평균 편향이 +152.09사이클이고 24셀에서 과대 예측이었다. 입력 범위를 벗어난 11셀도 따로 존재한다. 전체 배치를 범위 안이라고 해석하지 않는다. 실제 수명으로 나눈 단·장수명 구간은 평가 결과를 설명하는 사후 진단이며 신규 셀의 적용 허용 기준으로 사용할 수 없다.

## I5. 품질 검토와 예측 대상 축소의 구분

**관찰:** Batch 2 IQR 제외 표시 9셀; 장수명>1000 3→0셀; Batch 3 품질 민감도 44→40셀, MAPE 12.74→12.78%

**해석:** 일괄 이상치 제거는 중요한 수명 영역을 없앨 수 있다. 저자 품질 규칙을 대응시킨 검토에서도 외부 오차가 크게 줄지 않았다.

**의사결정 시사점:** 품질 문제는 측정 이력으로 판단하고, 정상적인 극단 수명은 검증 대상으로 보존한다. 정제보다 라벨 완료 여부와 표본 범위를 먼저 점검한다.

**해석 조건:** IQR은 타깃 분포의 진단이며 실제 셀 삭제나 초기 시점의 품질 판정 규칙으로 사용하지 않았다.

근거: [data/processed/cells_and_features.csv](../data/processed/cells_and_features.csv), [results/batch3_quality_sensitivity.csv](../results/batch3_quality_sensitivity.csv) · 개발·검증 보고서 11쪽 · EDA 1절과 모델링 9절의 품질 민감도

## I6. 절대 교체 시점과 상대 점검 순위의 분리

**관찰:** Batch 2/3 수명 순위 Spearman 0.709/0.797

**해석:** 절대 수명에 편향이 남아도 순위 정보는 일부 유지된다. 가능한 활용 목적에 따라 검증 기준이 달라진다.

**의사결정 시사점:** 점검 우선순위의 적용 가능성을 상위 위험 셀 탐지율·예산별 적중률로 별도 검증하고, 교체 자동 결정은 수명 구간별 교정과 현장 검증 이후 판단한다.

**해석 조건:** 순위 상관은 위험 셀 탐지 성능이나 비용 절감의 검증 결과가 아니다. 현장 적용은 별도 실험이 필요하다.

근거: [results/cell_predictions.csv](../results/cell_predictions.csv) · 개발·검증 보고서 12쪽 · 모델링 10절의 운영 해석

## 판단의 우선순위

| 우선순위 | 이번 증거가 요구하는 조치 | 확인할 성과 |
|---|---|---|
| 1. 정답·표본의 신뢰성 | 완전한 EOL·물리 셀ID 확인, 짧은·긴 수명 개발 표본 확보 | 라벨 완료율, 정책·구조·수명 구간별 표본 수 |
| 2. 새 조건의 교정 | 정책·셀 구조별 대응 관계를 새 집단에서 검증 | 구간별 MAE·bias, 단수명 과대 예측 손실, 예측구간 보정 |
| 3. 목적별 활용 검증 | 점검 순위와 교체 일정을 서로 다른 평가로 확인 | 예산별 위험 셀 적중률, 교체 오류 비용 |
| 4. 현장 입력 검증 | SOC·DoD·온도·캘린더 열화·팩 편차에서 초기 관측 가용성 확인 | 데이터 수집률·결측률, 100사이클 선별 소요시간 |

이 우선순위는 현재 결과에서 도출한 검증 계획이다. 현장 비용 절감이나 자동 교체 성능의 실증 결과로 해석하지 않는다. 정책·구조·수집 시기의 영향은 관찰 자료의 원인 가설이며 인과 효과를 분리한 결과가 아니다.


시사점 계산은 고정 평가 이후의 해석 단계다. 모델·분할·후보 선택 기준을 변경하지 않는다. 이전 배치 탐색 이력과 라벨·식별자 한계는 개발·검증 보고서의 평가 전제와 함께 읽는다.
